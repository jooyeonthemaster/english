이번 업데이트로 "어디를 출제할지"를 선생님이 직접 정할 수 있게 되었습니다.

**① 포인트 짚어주기 (신기능)**

- 문제 생성 시 지문에서 단어·구·문장을 직접 클릭하거나 드래그해 출제 포인트로 지정할 수 있습니다. 클릭 한 번이면 단어, 더블클릭이면 문장 전체가 선택됩니다.
- 지정한 포인트는 문제에 **반드시 반영되도록 검증**됩니다 — 빈칸·어법 밑줄·삽입 문장 등이 짚어 주신 자리에 정확히 출제되며, 어긋난 결과는 자동으로 반려하고 다시 만듭니다.
- 어디를 짚을지 막막할 때는 AI 제안 버튼으로 추천 포인트를 받아 골라 담을 수 있고(무료), 어법 유형은 문법 분류 태그(수일치·능동/수동 등)까지 붙일 수 있습니다.
- 만들어진 문제의 상세 화면에서 어떤 포인트로 만든 문항인지 지문 위에 그대로 표시됩니다.

**② 시험 리포트 — 채점과 분석이 나뉘었습니다**

- 학생 시험 관리가 수집 → 채점 → 분석 → AI 리포트 4단계로 정리되었습니다.
- 채점을 확정하면 **분석 허브**에서 정답률, 유형·난이도·개념별 취약점, 문항별 정오를 크레딧 소모 없이 바로 확인할 수 있습니다. AI 리포트는 필요할 때만 생성하면 됩니다.

**③ 프리미엄 문제 품질 상향**

- 어법 판단 프리미엄 생성이 3단계 검증 파이프라인으로 전면 개편되어, 내부 실측 기준 합격률이 크게 올랐습니다.
- 프리미엄 플랜 전 유형의 생성 모델을 상향했습니다. 어려운 지문일수록 차이가 큽니다.
