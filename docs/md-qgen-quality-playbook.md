# md-qgen 품질 개편 플레이북 — 어법·빈칸 킬러 캠페인에서 실효가 증명된 것들

> 26-08-21~22 어법·빈칸 킬러 대개편의 실측 결론을 전 유형·전 난이도에 적용하기
> 위한 정본. **여기 적힌 수치는 전부 실측이다** — 팬아웃 에이전트는 이 문서와
> 자기 유형의 코드·코퍼스만 근거로 삼고, 여기 없는 주장은 직접 측정해서 쓴다.

## 0. 불변 원칙

- **제1규칙(지문 인정)**: 지문은 절대 반려·수정·필터하지 않는다. 품질은 "이
  지문 안에서 최선인가"로만 판정한다.
- **난이도 라벨은 사용자 선택이 정본**이다. AI로 난이도를 재검수하지 않는다.
- **차단 게이트의 배선 기준 = 기출 오반려 0%.** 수능·평가원·학평 기출을
  게이트에 넣어 1건이라도 반려되면 그 검사는 차단 자격이 없다 — 임계를 기출
  분포의 관측 최대 밖으로 물리든가, 비차단 권고로 강등한다. "그럴듯한 품질
  규칙"이 기출과 다른 구조를 강제하는 것이 이 리포의 반복 사고 유형이다.
- **0원 게이트만**: md-stream 게이트는 LLM 콜 없는 결정형만. 게이트 메시지는
  그대로 [반려 재생성] 피드백이 된다 — "어느 라벨의 무엇이 왜 + 어떻게 고칠지"
  를 반드시 적는다.
- **킬스위치**: 모든 신규 게이트는 `QGEN_*=off` env 로 재빌드 없이 무력화
  가능해야 한다.

## 1. 실효가 증명된 개입 (어법·빈칸 실측)

| 개입 | 실측 효과 | 일반화 조건 |
|---|---|---|
| 죽은 선지 결정형 게이트 + 사유 피드백 재생성 | 30지문 중 반려 5건 재생성 → 개선 5/동일 0/악화 0, 죽은미끼 분포 {0:30} | 임계를 기출 분포에서 도출(어법: 기출 {0:133, 1:23, 2+:0} → 임계 2) |
| 프롬프트 기존 규칙의 **집행** 게이트 | 프롬프트가 이미 금지한 자리를 모델이 반복 위반 — 게이트가 잡자 즉시 교정 | "규칙은 있는데 확인 코드가 없다"가 기본 상태라고 가정하라 |
| 미끼 포인트 기출 분포 주입 | 관계사 미끼 7%→23%(기출 18%), 형/부 21%→13%(기출 8%) | 유형별 기출 분포를 먼저 실측해야 주입할 수 있다 |
| 정답 자리 소음·위치 게이트(answer-site) | 정답이 요란+첫 자리면 미끼 검토 전멸(0.00 vs 기출 0.79) — 복합 조건(첫 밑줄+접속사류)은 기출 0건 | 단독 신호는 오반려(① 단독 6.4%) — **복합 조건으로만** |
| 인용-앵커 해설(원문 축자 복사 → 분석) | 위치 허위·구조 날조 해설 차단 | 해설이 지문 구조를 서술하는 모든 유형 |
| 해설 용어 명명 규칙 | "동사원형" 오명명 재발 2회 → 규칙 추가 | 대용(代用) 계열은 예외 필요 — 지시 대상·원 술어는 다른 절이라도 반드시 짚는다 |
| 과반려 게이트 강등 (요약문 견본) | 반쪽정답 강제 = 기출 84.6% 오반려(수능 본시험 81.3%) → 전 난이도 비차단 강등 + 열 편차 임계 3→6(기출 최대 6) → 오반려 0% | 완화 조건도 0% FP 불가면 차단이 아니라 권고다 |

## 2. 측정 도구와 그 한계 (돈 쓰기 전에 읽어라)

- **정답률은 난이도 계기가 아니다.** 3.7-flash 솔버는 기출 수능 어법 95~98%,
  약화 시도 전멸: 모델 축소(3.1-flash-lite) 98%, 페르소나 약화(3등급+90초)
  100%. LLM은 파싱 능력을 연기로 못 낮춘다. **논의 종결.**
- **유효 지표는 검토율(seriouslyConsidered)뿐** — 기출 미끼 0.79 vs 불량품
  0.00을 가른다. 보조 지표: 차점 집중도(기출 93%).
- **슬롯 생존율은 자리 고유 속성이 아니라 정답에 조건부다.** 같은 자리가 정답
  구성에 따라 10/10↔0/10. 슬롯 단위 직관 예측은 외부 평가자도 2라운드 연속
  4/6 오판했다 — **측정으로만 판정한다.**
- **n=10에서 0.1~0.2 차이는 보고 금지.** 방향 판정에만 쓴다.
- **지표에서 정답을 빼고 미끼만 세라** (정답 포함은 상수 +1 왜곡).

## 3. 유형×난이도 기출 기준선 (표면 신호, 우연=20%)

등급(고1/고2/고3)을 기본/중급/킬러의 대리변수로 쓴다. 요지: **표면 신호
억제는 난이도 의존 규칙이다** — 기출조차 고1에서 더 느슨하다.

- 정답=최장 선지: 요지 34.8%·내용일치 27.7%·주장 25%(고1은 더 높음: 40.7%,
  36.5%) → **길이 게이트 금지**, 프롬프트 레버만.
- 정답=어휘 겹침 최대: 제목 고1 43.9% vs 고3 26.9%, 주제 44.9% vs 30.8%.
- 정답 라벨 비대칭(게이트 후보): 무관한문장 ③④ 92.8%(①⑤ 합 1.2%) ·
  글의순서 ① 1.8% · 문장삽입 ① 2.0% · 어법 ① 6.4%.
- 요약문 미끼 절대어 73% = 기출 정상 패턴 → 절대어 게이트 금지.
- 요약문 조합 구조: 반쪽정답 둘다 17.3% / A쪽만 59.6% / 없음 16.7% —
  평가원 정형은 "(A)열 중복·(B)열 전부 다름".

## 4. 유형별 적용 사이클 (순서 고정)

1. **해부**: 기출 코퍼스(`scratchpad/types/*.all.json` 또는
   `src/data/exam-passages/`)에서 이 유형의 구조 실측 — 정답 라벨 분포,
   선지 형태, 유형 고유 계약.
2. **게이트 실사**: 현행 `gate-*.ts`에 기출을 넣어 오반려율 실측
   (견본: `scripts/_tmp-summary-fp.ts` 패턴 — 기출에 없는 필드는 중립
   합성값으로 채우고 그 범주는 집계에서 제외).
3. **실생성**: 프로덕션 프롬프트로 3.7-flash 실생성 → 같은 계기로 측정 →
   기출과의 갭 확인.
4. **갭 수정**: 프롬프트(실측 근거 명시) → 재생성으로 효과 검증(전/후 비교).
5. **게이트 신설/수정**: 기출 오반려 0% + 음성테스트(결함 주입해 울리는지)
   + 킬스위치. 이후 라우트/레인 배선.
6. **E2E**: 게이트 포함 전체 경로 재생성 n≥10, 기출 기준선 대비 보고.

## 5. 재발 금지 함정 (전부 실전 사고)

- 기출 파싱 오염 2종: 장문 answerKey 가 중첩 객체(`{"45":{"45":4,...}}`) ·
  마지막 선지 꼬리에 OCR로 다음 문제 전체가 붙음("홀수형 [41~42] …").
  **계기 음성테스트 없이 측정 금지.**
- `0/0`을 `0%`로 찍는 코드 — 조건별 n 을 반드시 같이 출력.
- 오류 변형 실험에서 기존 오형 미복원(2오류 문항) — 오류불변식 assert 필수.
- Git Bash `/tmp` ≠ Node `D:\tmp` — 절대경로 한 종류로 통일.
- JS 템플릿 리터럴을 Python 치환으로 수정 금지(백슬래시 파손).
- 검증 전에 품질 단정 금지 — 기출 하한(어법 살아있는선택지 1.00이 기출 11%)
  을 모르면 "미달" 판정 자체가 오판이다.
