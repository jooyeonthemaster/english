#### BookFest 독서 취향 테스트 (BOOK PERSONA)

- **틴더식 카드 스와이프 판정 UX** — 마우스 드래그로 12장 전부 완주, 드래그 중 카드가 기울며 YES/AGREE 스탬프가 찍히는 것 실측
- **명문장 12장 × 해시태그 큐레이션** — #고독부터 #변화까지 12장 전량 실측 기록
- **16유형 4축 퍼스낼리티 매트릭스** — 결과 페이지 4축 슬라이더 실측, JS 번들에서 16개 코드 전량 추출 확인
