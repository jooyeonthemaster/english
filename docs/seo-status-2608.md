## 3. 확정 결함 원장

### D1 [Critical] 구글 사이트맵 제출 크론이 매일 403으로 죽고 있다

- `vercel.json` 크론: `/api/seo/submit` 매일 03:00
- `/api/seo/submit` 라이브 응답: `gsc.configured: true`
- **그러나** `gscConfigured()` 는 *SA JSON이 파싱되는지만* 검사하고 실제 권한은 안 본다
- `loadServiceAccount()` 폴백 체인:
  `GOOGLE_SEARCH_CONSOLE_SERVICE_ACCOUNT_B64` → **`GOOGLE_DOC_AI_SERVICE_ACCOUNT_B64`**
- Vercel 운영 env 전수(116개) 조회 결과 — **`GOOGLE_SEARCH_CONSOLE_SERVICE_ACCOUNT_B64` 없음.**
  존재하는 GOOGLE 키는 `GOOGLE_DOC_AI_*` 4개 + `GOOGLE_GENERATIVE_AI_API_KEY` 뿐
- 즉 크론은 **Doc AI 서비스계정으로 GSC를 호출**하고 있다
- 그 SA(`nara-document-ai@nara-ai-496105`)로 직접 GSC API를 때려본 실측 결과:

```
토큰 발급 OK
사이트 목록 status: 403
"Google Search Console API has not been used in project 318358024789
 before or it is disabled."
```

**결론: 프로젝트에 Search Console API 자체가 비활성이라, 매일 새벽 사이트맵 제출이
403으로 실패해 왔다.** 색인 갱신 통지가 구글 쪽으로는 나간 적이 없다.

> 완화 요인: 네이버·Bing 쪽 IndexNow 는 별개 경로로 정상 동작 중이고(키 검증 통과),
> 구글도 robots.txt 의 `Sitemap:` 라인으로 사이트맵을 발견할 수 있다. 그래서
> "색인이 아예 안 됐다"는 아니다 — 실제로 색인은 되고 있다. 손실은 **갱신 통지 속도**다.

**수리 경로(둘 중 하나)**
- (a) GCP 프로젝트 `nara-ai-496105` 에서 Search Console API 활성화 +
  SA 이메일을 GSC 속성에 "소유자"로 추가 → 폴백 그대로 동작
- (b) 별도 SA를 만들어 `GOOGLE_SEARCH_CONSOLE_SERVICE_ACCOUNT_B64` 를 Vercel 운영 env 에 주입
- 추가 권장: `gscConfigured()` 가 권한까지 확인하도록 고치거나, 크론 실패를 알림으로 승격.
  **지금은 조용히 실패해서 아무도 몰랐다.**

28일일 수가 없다. 아래 §4.3·§4.4의 구글 장기 수치는 3개월 기준이다.

### 4.1b 【핵심】 성장의 실체는 비브랜드 폭증이다

28일 총 119클릭 중 **마지막 7일이 48클릭 = 40%**. 앞 21일은 주당 23.7, 마지막 주는 48 —
**주당 2배**로 가속 중이다. 그런데 그 안을 브랜드/비브랜드로 가르면 그림이 선명해진다.

| 구간 | 총 클릭(주당) | 브랜드(주당) | **비브랜드(주당)** |
|---|---:|---:|---:|
| 3개월 평균 | ≈15.4 | **4.8** | ≈10.6 |
| 최근 7일 | **48** | **4** | **44** |

- **브랜드(`smoat`·`스모트`)는 주당 5클릭 안팎으로 사실상 상수다.**
  (3개월 62클릭 ÷ 13주 = 4.8 → 최근 7일 4. 일치)
- **비브랜드는 주당 ~10.6 → 44 로 4배 이상 폭증.** 브랜드 비중도 3개월 31% → 최근 7일 8.3%.

**이게 진짜 SEO 성과다.** 새로운 사람들이 우리를 모르는 상태에서 검색으로 발견하고 있다.

**동시에 경고 신호이기도 하다**(추정): §4.4대로 브랜드 검색량이 비검색 채널의 대리 지표라면,
**그게 3개월째 주당 5로 정체**라는 건 인스타·영업·입소문 쪽이 새 인지를 만들어내지 못하고
있다는 뜻일 수 있다. 다만 브랜드 검색은 후행·노이즈가 큰 대리 지표라 이것만으로 단정할 수
없다 — §3 D2 계기를 심어야 확인된다.

**CTR 이 못 박혀 있다는 점도 중요하다.** 7일과 28일 모두 CTR 3.9%, 평균순위 7.2~7.3으로
동일하다. 즉 성장은 **순위·CTR 개선이 아니라 노출 물량 증가**에서만 나오고 있다.
노출은 콘텐츠 누적으로 알아서 늘고 있으니, **우리가 지금 당장 손댈 수 있는 레버는 CTR 하나뿐**이다
(§4.2). CTR 3.9% → 6% 만 되어도 새 콘텐츠 0개로 클릭 +54%다.

검색어를 의도별로 갈랐더니 **CTR이 한 자릿수 배로 갈린다.**

**「양식」계열 — 노출 대량, CTR 1~2% (참사)**

안 눌린다. 반면 「제작·만들기·방법」은 도구를 찾는 의도라 우리 페이지와 맞아 CTR 15%대다.

이건 **우리가 이미 가진 자산으로 메울 수 있는 격차**다 — HWPX/Word 시험지 조판 엔진이
이미 있으므로(직전 커밋 b28bcd98), 실제 다운로드 가능한 무료 양식 파일을 놓으면
의도를 충족시키면서 SMOAT 로 유도할 수 있다.

### 4.4 브랜드 검색이 1위 — 그런데 이건 SEO 성과가 아니다

| 엔진 / 구간 | 브랜드 클릭 | 총 클릭 | 비중 |
|---|---:|---:|---:|
| 구글 3개월 | smoat 51 + 스모트 11 = **62** | ≈200 | **~31%** |
| 구글 최근 7일 | smoat 3 + 스모트 1 = **4** | 48 | **8.3%** ↓ |
| 네이버 30일 | smoat 20 + 스모트 10 = **30** | 160 | **~19%** |

브랜드 비중이 31% → 8.3% 로 떨어진 건 브랜드가 줄어서가 아니라 **비브랜드가 4배로 늘어서**다(§4.1b).

`smoat`·`스모트`를 검색하는 사람은 **이미 우리를 안다.** 인스타·영업·입소문·세미나 어딘가에서
인지한 뒤 검색창을 내비게이션으로 쓴 것이다. 따라서

- **브랜드 검색 클릭을 SEO 획득 성과로 계상하면 안 된다** — 이중계상이다.
- 거꾸로 **브랜드 검색량 추이 = 비검색 채널(인스타 등)의 대리 지표**로 쓸 수 있다.
  계기를 심기 전까지는 이게 인스타 효과를 볼 수 있는 유일한 창이다.

### 4.5 규모 감각 — SEO 는 아직 우리 주력 획득 채널이 아니다

- 월 검색 클릭 ≈ **287** (브랜드 제외 시 ≈ **220**)
- 같은 달(8월) 학원 가입 = **32건**

가입 32건이 전부 검색에서 나왔다면 CVR 11% — B2B SaaS 신규 가입 기준으로 비현실적으로
높다. 따라서 **가입 대부분은 검색이 아닌 경로에서 온다**고 보는 게 합리적이다(추정).

즉 SEO 는 **가파르게 성장 중이지만(비브랜드 주당 10.6→44, 네이버 전월비 +413%) 아직 작다.**
6월→7월 가입 급감(96→35)을 SEO 로 설명할 수는 없고, 여전히 §3 D2 의 계기 부재 때문에
**진짜 주력 채널이 무엇인지 모르는 상태**다.

다만 추세는 분명하다 — 이 속도가 유지되면 SEO 는 몇 달 안에 유의미한 획득 채널이 된다.
지금 CTR 을 고쳐두면 그 물량이 그대로 증폭된다.

### 4.6 【핵심】 구글은 "우리 서비스와 무관한 키워드"로 잡혀 있다

사용자 지적을 검증한 결과 **사실로 확인됐다.** 잡히는 키워드의 성격이 두 엔진에서 근본적으로 다르다.

**클릭 기준 — 비브랜드 클릭 중 「영어」 토큰을 포함한 비율**

|---|---:|---:|---:|
| **구글 3개월** | 21 | 4 | **19%** |
| **네이버 30일** | 27 | 21 | **78%** |

우리 **고유 기능 토큰**(변형문제·지문분석·구문·학습지)으로 좁히면 격차가 더 벌어진다.

- 구글 3개월: 「수능특강 영어 변형문제」 단 1종 (노출 11)
- 네이버 30일: 「영어 변형문제 제작」(82) · 「영어 지문 분석 방법」(31) · 「영어 구문 분석」(19) ·

**즉 구글에서 우리는 「시험지 양식」이라는 범용 문서-템플릿 쿼리로 잡혀 있고,
네이버에서는 「영어 변형문제 제작」이라는 우리 정체성 그대로 잡혀 있다.**

#### 원인 — `/resources` 한 페이지가 구글 노출 프로필을 왜곡하고 있다

`/resources`는 구글 최대 노출 자산(3개월 938노출)인데, 페이지 자체는 **영어를 정조준해 만들어져 있다**:

- title: `무료자료실 — 영어 시험지 양식·채점기준표·단어시험지 | 스모트 SMOAT`
- h1: `영어 시험지 양식·채점기준표 무료 다운로드`
- 실제 배포 파일 3종 존재 — `smoat-english-exam-template.docx`,
  `smoat-grading-rubric-template.docx`, `smoat-vocab-test-template.docx`

**그런데 구글은 이 페이지를 「시험지 양식」(범용, 162노출)으로 랭크시켰고,
정작 「영어 시험지 양식」은 17노출뿐이다.** 우리 의도와 구글 해석이 어긋나 있다.

#### CTR 1~2%는 개선 대상이 아니라 「부적합」의 증거다

§4.2에서 「양식」 계열 저CTR을 개선 과제로 잡았으나 **이 판단을 철회한다.**

「시험지 양식」 검색자는 검색결과에서 우리 제목(`무료자료실 — 영어 시험지 양식…`)을 보고
**"영어구나, 내가 찾는 게 아니네" 하고 지나간다.** CTR 1.9%가 바로 그 증거다.
여기서 CTR 을 억지로 끌어올리면 **전환되지 않는 트래픽만 증폭**된다 —
영어학원 원장이 아닌 사람을 더 많이 데려오는 것뿐이다.

> **철회한 제안 2건 (2026-08-27 이전 판)**
> 1. ~~`/resources`에 무료 양식 다운로드 배치~~ → **이미 되어 있다.** docx 3종 실재 확인.
> 2. ~~「양식」 쿼리 CTR 개선을 P0로~~ → **역효과.** 범용 쿼리 CTR 상승 = 무자격 트래픽 증폭.

#### 반전 — 구글 최근 7일은 이미 방향이 바뀌었다

3개월 프로필은 과거다. **최근 7일 비브랜드 클릭 10건 중 7건이 영어 특정 + 6건이
「만들기·프로그램·사이트」 도구 탐색 의도**다.

```
영단어 시험지 만들기 프로그램 / 영어 단어 시험지 만들기 사이트 /
영어 단어 시험지 만들기 / 영단어 시험지 만들기 사이트 /
영어 단어장 양식 word / 수능특강 영어 변형문제
```

이건 우리가 원하던 의도군이다. **구글도 교정되는 중**이며, 3개월 표만 보고
"구글 SEO는 글렀다"고 결론내리면 오독이다.

> ⚠️ **계기 한계**: GSC·서치어드바이저 검색어 표는 **클릭 기준 정렬**이다. 따라서
> 노출은 많은데 클릭이 0인 쿼리(범용 「양식」류의 상당수)는 이 표에 아예 안 나온다.
> 위 비율은 전부 **클릭 가중치** 기준이며, 노출 분포의 완전한 그림이 아니다.
> 확정하려면 GSC 에서 **노출 기준 정렬**로 다시 봐야 한다 → §5 후속.

|---|---:|---|---|
| **types** | **21 (36%)** | 「빈칸추론 문제」·「지칭 추론 문제」 | **"그게 뭐야?" — 학생·정보탐색** |
| guides | 18 | 「영어 어법 문제 만들기」 | 혼재 |
| exams | 10 | 「수능특강 영어 변형문제」 | 수능축 |
| textbooks | 9 | 「동아 영어 교과서 변형문제」 | **원장·도구탐색** ✓ |

최대 카테고리 **types 21건이 가장 전환이 안 되는 축**이다. 「빈칸추론 문제」를 검색하는
사람은 대개 학생이지 학원 원장이 아니다. `/types` 성과가 그대로 증명한다 — **136노출 4클릭, CTR 2.9%.**

반면 사용자가 지목한 8개 키워드는 **전부 원장 의도**(제작·AI·도구)다.
**우리는 학생이 칠 말에 21건을 쓰고, 원장이 칠 말에 0건을 썼다.**

#### 허브는 있는데 스포크가 딴 데를 가리킨다

`/features/ai-question-generation` 의 라이브 메타는 이미 정확하다 —
`AI 영어 문제 생성 — 내신·수능 24유형 자동 출제`. **내신·AI·생성이 다 들어 있다.**
그런데 3개월 노출이 **51**뿐이다.

페이지가 없어서가 아니라, **이 허브를 떠받칠 스포크(articles 58건)가 전부 다른 방향을
가리켜 토픽 권위가 쌓이지 않기 때문**으로 보인다(추정). 내부 링크가
「내신 변형문제 AI」로 수렴하지 않는다.

### 4.8 아직도 답할 수 없는 것

- 인스타·카톡·직접입력의 실제 유입량 → 계기 부재(§3 D2)
- 어떤 랜딩이 가입으로 이어지는지 → 전환 추적 없음
- 6월→7월 가입 급감 원인 → 채널별 분해 불가
