# 1회 호출 성공(first-call-right) 캠페인 연구노트 — 2026-07-06 저녁

## 골(사용자 지시)
킬러 평균 LLM 호출 2.2회(ST)/1.9회(PREM)는 절대 불가 — "아름다운 문제를 1회에". 게이트 완화 금지.

## 실측 기준선 (오늘 전체 아티팩트, usageEvents 기준)
- 전체: ST 1.88콜/문항, PREM 1.66콜/문항 (중급 ~1.4, 킬러 ST 2.22 / PREM 1.83)
- GRAMMAR_ERROR만(46레코드, repair 콜 포함): ST 3.27 / PREM 2.80, 구제출하 50%
- 비용: ST $0.064/문항, PREM $0.088/문항 (입력 29k tok가 지배 — 재시도 1회 = 전액 재지불)
- 낭비의 80% = 어법 KILLER 품질 반려. 빈칸 잔여 0.4콜은 lean repair(3k, 정상 동작)

## 진단 확정 사실 (Opus 5 + Fable 3 병렬 진단)
1. **실패 지배축 = 정답 자리(72% 레코드)**, 미끼는 13%만 단독 원인. 구제출하 23건 중 22건이 정답자리 깊이 코드.
2. **프롬프트 자해 3종**: (a) 품질계약의 타 유형 62줄이 어법 프롬프트의 25%(~4.6k tok) 점유, (b) 금지표면 블록 2회 중복 인쇄, (c) frame5가 'N+what' 변형을 정답 레시피로 권장 ↔ 게이트가 정확히 그걸 반려(오늘 16회). 후보목록에 잘린 표현("...biolo...")·엉뚱한 trap 노이즈.
3. **자동수리 가능 반려는 좁음(2/15)**: 동일마커 dedup + 역할스왑(expression:=correction, 지문실재 이중검사)만 안전. 나머지는 진성 모델 실패 — abstain이 정답.
4. **passageWithMarkers는 AI 출력이 아님** — 서버가 원문+markedExpressions로 조립. 선별 = 부분집합 → processGrammarError 재실행 (문자열 수술 금지).
5. **오류 2개 심기 변형은 구조적 폐기**: 스키마가 복수오류 해설 전항 커버를 강제 → 강등 시 자기모순 ~100%, 게이트 불가시. errorDesign도 단일정답 하드코딩.
6. **점수기 역선택 위험**: 게이트 여집합 최적화 → 게이트가 못 보는 결함(llmFatal류)이 선별로 농축. 깊이 휴리스틱은 거부권용 보정이라 랭커 전용 금지.
7. 지문 사전판별 게이트 기각(같은 지문에서 성공/구제 공존 — 분산 문제). repair 좌표계(셔플 전/후) 전례 = KO-GEN-3.

## 채택 설계
- **Wave 1 (프롬프트 무결성)**: 계약 타입필터(무손실 -4.6k tok, typeId 미지정=바이트동일 보증) + 금지블록 중복 제거 + frame5 충돌 수정 + KILLER N-what 금지 + depends 일반 경고 + 후보 노이즈 정리 + **말단 자기검증 체크리스트**(종결명령 직전, GRAMMAR_ERROR 전용).
- **Wave 2 (결정론 자동수리)**: dedup·역할스왑·용어치환('통사적으로'→'문장 구조상' 등 1:1만). abstain 조건 테스트 필수(playing/playing/played는 반려 유지).
- **Wave 3 (과잉생성+선별, 축소판)**: ① 게이트-일관 정답자리 메뉴(반려 술어 역적용 사전 열거 — 메뉴 술어=반려 술어라 오라벨 불가), ② 오류1+미끼6 요청 → 최상 4미끼 결정론 선별(부분집합→후처리 재실행), ③ 산문 정합 제약(해설/키포인트 참조 라벨 탈락 금지), ④ 점수기는 위반0 조합 동률깨기 전용, ⑤ 반려기록/풀/하드밴은 선별 5사이트만, 스키마 G=7/검증 K=5 이원화, 결핍판정 K기준.
- 후속 후보: 크로스어템프트 조립(salvage ① 승격, 0콜), 계약 타입필터의 타 유형 확대.
