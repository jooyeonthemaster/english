1. 자료 추출/자료 관리 카드 선택 UX
- 오른쪽 드로어 및 자료관리 드로어 카드에 드래그 셀렉(마키 선택)을 적용.
- 드로어가 열려 있을 때는 사이드바를 제외한 본문 어디서 드래그를 시작해도, 선택 대상은 드로어 내부 카드로만 제한.
- 카드 클릭 동작을 통일:
  카드 아무 곳 클릭 = 체크 선택/해제
  "상세 보기" 버튼 클릭 = 상세 드로어/상세 모달 열기
- 적용 대상:
  - 추출 페이지 자료 목록 카드
  - 자료관리 상단/하단 작업 카드
  - 오른쪽 프리뷰 드로어 내 자료 카드
  - 자료관리 상세 드로어 내 자료 카드
  - grid/list 작업 카드
- 드래그 핸들은 드래그 셀렉에서 제외해 폴더 이동 드래그와 충돌하지 않도록 처리.
- 선택 집합은 현재 화면/드로어에 표시되는 카드 기준으로 계산해, 다른 작업의 stale selection이 bulk action에 섞이지 않게 정리.

2. /director/workbench/extraction 페이지
- 자료 목록에 선택 상태를 연결.
- 카드 클릭으로 드로어가 열리지 않고 체크만 토글되도록 변경.
- 상세 드로어는 "상세 보기" 버튼을 누를 때만 열림.
- 자료 목록에서도 드래그 셀렉으로 여러 작업 카드를 선택할 수 있음.

3. 공용 DragSelect 개선
- 시작 영역(boundary)과 실제 선택 대상 영역(item scope)을 분리하는 itemScopeRef 추가.
- capture 단계에서 mousedown을 감지해 카드 내부에서 이벤트 전파가 끊겨도 드래그 셀렉이 안정적으로 시작되도록 개선.
- 카드 내부 버튼/role=button 영역에서도 필요한 경우 마키 시작을 허용하는 옵션 추가.
- data-drag-select-ignore를 추가해 드래그 핸들 등 제외 영역을 명시.

4. 분석 리포트 편집기 변경
- 분석 리포트 편집기 좌측 페이지 레일/우측 편집 패널 폭을 드래그로 조절 가능하게 추가.
- 레일/패널 폭은 localStorage에 저장되어 다음 진입 시 유지됨.
- exam paper builder와 유사한 col-resize UX 적용.

5. 분석 리포트 워크시트 출력 개선
- 워크시트 정답 및 해설 영역을 하나의 큰 블록이 아니라 서브섹션별 독립 블록으로 분할.
- 긴 정답키가 한 페이지를 넘어갈 때 overflow로 잘리는 문제를 완화.
- 정답 서브섹션은 break-inside: avoid로 라벨만 페이지 하단에 떨어지는 케이스를 방지.
- 깨진 placeholder 문구를 정상 한국어로 수정:
  - (원문 구절)
  - (함정 포인트)
  - (묻는 것)
- 어휘 테스트 빈칸/정답 라인의 두께와 opacity를 조금 강화해 출력 가독성 개선.
