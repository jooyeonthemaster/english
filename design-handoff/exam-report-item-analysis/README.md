# Handoff: 내신 시험 분석 — 문항 분석 워크스페이스 리디자인

## Overview
SMOAT(영어학원용 AI 올인원 서비스)의 "내신 시험 분석" 워크스페이스 1단계(문항 분석) 리디자인. 강사가 AI가 추출한 채점 지도(문항별 종류·배점·정답)를 **실제로 검증**하도록 강제하고, 부차적인 문항별 분석 검수에 잡아먹히지 않게 하는 것이 목표. 정답·배점 22/22 확인 전까지 2단계(학생 관리)는 잠긴다.

**최종 방향: 데스크톱 = 시안 B(채점 지도 주인공 + 우측 분석 서랍), 모바일 = 시안 A(스텝 플로우).**

## About the Design Files
이 번들의 파일은 **HTML로 제작된 디자인 레퍼런스**입니다 — 의도된 look & behavior를 보여주는 프로토타입이지, 그대로 복사할 프로덕션 코드가 아닙니다. 과제는 이 디자인을 **대상 코드베이스의 기존 환경**(React/Next.js + Tailwind + shadcn 등 기존 패턴과 라이브러리)으로 재구현하는 것입니다. 기존 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 골라 구현하세요.

## Fidelity
**High-fidelity.** 색·타이포·간격·상태가 SMOAT 디자인 시스템 기준의 최종값입니다. 픽셀 수준으로 재현하되, 코드베이스의 기존 공용 컴포넌트(Input, Select, Badge, FilterPill, SaveButton 등)에 매핑하세요.

## Interactions & Behavior
- **게이트**: `confirmedCount < 22`이면 학생 관리 진입 차단(라우트 가드 포함). 버튼은 `aria-disabled` + 클릭 시 첫 미확인 문항으로 스크롤 + 힌트 글로우 애니메이션(`smoat-hint-glow` keyframes, 1.5s, DS Patterns/hint-glow 참조).
- **행 확인**: 확인 버튼 클릭 또는 셀 편집 중 Enter → 해당 행 confirmed(점 초록, 버튼 solid emerald) → 포커스 다음 미확인 행 첫 편집 셀로 이동.
- **값 수정 시**: confirmed 행의 배점/정답이 바뀌면 확인 상태 해제(다시 파랑) — 수정 후 재확인 강제. 채점된 학생이 있으면 재집계 + 토스트/알림.
- **저장**: 셀 단위 낙관적 업데이트, 500ms 디바운스 배치 저장, 저장 중에도 입력 잠금 없음. 실패 시 셀에 red 표시 + 재시도.
- **재분석**: 실패 문항에서 실행(무료). 진행 중엔 파랑 진행 스트립: 스피너 + "보통 5~6분 걸려요 — 화면이 조용해도 서버가 계속 작업 중이에요. 이 페이지를 떠나도 진행됩니다." + 경과 시간(mm:ss). **5~6분 무응답을 정상으로 전제한 카피/디자인** — 퍼센트 게이지로 속이지 말 것.
- 서랍 열기: 표 행 클릭 또는 분석 아이콘. 이전/다음 화살표로 문항 이동. 원본 사진은 서랍 탭.
- 필터 필/검색: 클라이언트 라이브 필터(250ms 디바운스).

## State Management
- `questions[22]`: { no(string — "서답형 3" 가능), kind(객관식|단답형|서술형), typeLabel, prompt, points(number|null), answer(string), confirmed(bool), analysis{6 fields}, analysisReviewed(bool), analysisStatus(done|failed|running) }
- `overview`(총평 텍스트, 편집 가능), `difficultyProfile{easy:4,normal:11,hard:5,killer:2}`
- 파생: `confirmedCount`, `partialSum`(points 입력분 합), `missingPointsCount`, `gateOpen = confirmedCount===22`
- UI: `selectedQuestion`, `sheetTab`, `statusFilter`, `typeFilter`, `searchQuery`, `bulkPopoverOpen`
- 서버: 문항 단위 PATCH 큐(디바운스 배치), 재분석 job polling(긴 침묵 허용, 지수 백오프)
