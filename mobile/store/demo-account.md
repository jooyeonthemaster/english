# 심사용 데모 계정 안내

App Store Connect의 `로그인 필요 = 예`와 Google Play Console `앱 액세스 권한`에 공통으로 사용합니다. `SMOAT 학습`은 학생이 앱 안에서 회원가입을 하지 않고, 학원 강사가 발급한 **학원코드 + 학생코드**로 로그인하는 B2B2C 구조이므로, 심사자가 콘텐츠를 확인하려면 시드 계정이 반드시 필요합니다.

## 로그인 구조

학생 로그인은 두 코드로만 이루어집니다(근거: `src/app/g/login-client.tsx`).

- **학원코드(Academy code)** — 학원마다 발급되는 식별 코드. 3자 이상, 대문자 자동 변환.
- **학생코드(Student code)** — 학생마다 발급되는 코드. 4자 이상, 대문자 자동 변환.

이메일·비밀번호·전화번호 입력이 없으며, 앱 내 회원가입 화면도 없습니다. 코드는 담당 강사가 `/director`(강사 전용 웹)에서 발급합니다.

## 콘솔 필드 매핑

### App Store Connect(App Review Information)
- **로그인 필요**: 예
- **사용자 이름(User name)**: 학원코드를 입력합니다.
- **암호(Password)**: 학생코드를 입력합니다.
- **비고(Notes)**: "학생 로그인은 이메일/비밀번호가 아니라 학원코드(사용자 이름 칸)와 학생코드(암호 칸)의 조합입니다. 아래 자동 로그인 링크를 사용하면 코드 입력 없이 바로 진입할 수 있습니다."라고 기재합니다.

### Google Play Console(앱 액세스 권한)
- **로그인 자격 증명이 필요한 앱**을 선택합니다.
- **사용자 이름**: 학원코드
- **비밀번호**: 학생코드
- **안내**: App Store Connect와 동일한 설명을 기재하고, 자동 로그인 링크를 함께 남깁니다.

## 자동 로그인 딥링크

강사 공유 링크와 동일한 프리필 자동 로그인을 심사자에게 제공합니다. 아래 URL을 열면 두 코드가 채워진 상태로 1회 자동 로그인이 시도됩니다(근거: `src/app/g/login-client.tsx`에서 `?ac`/`?sc` 프리필이 들어오면 `useEffect`가 1회 `doLogin`을 호출).

```
https://www.smoat.co.kr/g?ac=<학원코드>&sc=<학생코드>
```

- 앱 미설치 브라우저에서도 동일하게 `/g` 웹 로그인이 동작합니다(기능 손실 0).
- 앱 설치 기기에서는 App Links로 앱이 열립니다(범위 `/g`·`/g/*`, 근거: U2 매니페스트 · U5 `assetlinks.json`).
- 명시적 앱 열기가 필요하면 커스텀 스킴 `smoat://g?ac=<학원코드>&sc=<학생코드>`를 사용합니다(근거: U2 매니페스트 `smoat` 스킴).

## 시드 계정 요구사항(빈 화면 반려 회피)

Apple 2.1·Google 최소 기능 반려를 피하려면, 심사자가 로그인한 직후 **비어 있지 않은 화면**을 보아야 합니다. 시드 학생 계정은 다음을 갖추어야 합니다.

- 계정 상태: **ACTIVE**(로그인 즉시 홈 진입).
- **과제 표본**: `/g/tasks`에 미완료·완료 과제가 최소 1건씩(학습지·퀴즈 각 1건 권장).
- **시험 표본**: 타이머 응시(`/t`)로 진입 가능한 배정 시험 1건 + 완료 기록 1건.
- **어법 드릴 이력**: 여러 유닛에 걸친 풀이 기록이 있어 `/g/me` 숙달 히트맵과 14일 활동 계기판이 채워질 것.
- **AI 튜터 이력(선택)**: 어법 튜터 질문 1~2건(무과금·정답 비노출 동작 시연용).

개인정보 노출을 피하기 위해 학생 이름은 가명(예: `홍길동`)으로 시드합니다. 실명·실제 학부모 정보를 넣지 않습니다.

| 항목 | 값 |
| --- | --- |
| 학원코드(사용자 이름) | `확정 필요` |
| 학생코드(암호) | `확정 필요` |
| 자동 로그인 링크 | `https://www.smoat.co.kr/g?ac=확정필요&sc=확정필요` |
| 시드 학생명(가명) | `확정 필요` |
| 유효기간 | 심사 기간 내내 ACTIVE 유지(만료·비활성화 금지) |

> 주의: 심사 기간 동안 시드 계정을 비활성화하거나 코드를 재발급하면 심사자가 로그인하지 못해 반려로 이어집니다. 심사 결과가 나올 때까지 계정을 그대로 유지합니다.
