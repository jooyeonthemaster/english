# Google Play 콘텐츠 등급 (IARC 설문)

Google Play Console `콘텐츠 등급` 섹션은 IARC 설문을 통해 등급을 산정합니다. 아래는 `SMOAT 학습`의 정직한 답변과 근거입니다. 이 앱은 폭력·성적 콘텐츠·도박·약물 등 부적절 콘텐츠가 없는 학습 앱입니다.

## 설문 카테고리 선택

콘텐츠 등급 시작 시 앱 카테고리에서 `참고자료, 뉴스 또는 교육용`(Reference, News, or Educational)을 선택합니다. 게임이 아닙니다.

## 설문 답변

| 설문 항목 | 답변 | 근거 |
| --- | --- | --- |
| 폭력(만화·판타지·사실적) | 없음 | 학습 콘텐츠만 제공 |
| 성적 콘텐츠·노출 | 없음 | 어법·영어 학습 텍스트 |
| 욕설·저속어 | 없음 | 학습 텍스트, AI 튜터는 어법 전용·정중한 합니다체 |
| 약물·알코올·담배 | 없음 | 해당 콘텐츠 없음 |
| 도박(모의·실제) | 없음 | 결제·확률 요소 없음 |
| 공포·불쾌 콘텐츠 | 없음 | 해당 없음 |
| 사용자 간 상호작용·소통 기능 | 아래 주석 참조 | 학생 간 채팅·공유 없음. AI 튜터는 대인 소통이 아님 |
| 사용자 위치 공유 | 없음 | 위치 미수집 |
| 개인정보 공유 | 아래 주석 참조 | 데이터 안전 신고와 정합 |
| 디지털 구매 | 없음 | 학생 앱 내 결제·구매 없음 |

## 사용자 상호작용·AI 콘텐츠 주석

- 본 앱에는 학생 간 채팅, 커뮤니티, 콘텐츠 공유 같은 사용자 간 상호작용 기능이 없습니다. 따라서 `사용자 상호작용` 항목의 대인 소통은 `없음`으로 답합니다.
- AI 어법 튜터는 학생과 AI 모델 간의 1:1 학습 보조이며, 시스템 프롬프트로 어법 학습에 한정됩니다(잡담·타 과목·숙제 대행 거절). 출력은 정중한 합니다체이고, 미제출 문항의 정답을 노출하지 않습니다(근거: `api/grammar-drill/chat/route.ts`). AI 생성 콘텐츠 관련 설문이 별도로 제시되면, 콘텐츠가 어법 학습으로 제한되고 서버에서 컨텍스트를 조립하며 안전장치(어법 외 요청 거절, 마크다운 제거, 일일 사용 한도, 입력 길이 제한)가 있음을 근거로 답합니다.

## 예상 등급과 대상 연령층

- IARC 산정 등급은 부적절 콘텐츠 부재로 최저 수준(전체 이용가 계열)로 나올 가능성이 높습니다.
- 다만 Play `대상 연령층`은 콘텐츠 등급과 별개로 선택합니다. 본 앱은 **13-17세 및 18세 이상**을 대상으로 설정합니다.
  - 근거: 주 이용자는 고등학생입니다. 12세 이하를 제외해 가족 정책(Families Policy)상 아동 대상 앱의 추가 요건과 혼합 대상 처리 부담을 낮춥니다.
  - 13-17세를 포함하므로 미성년 대상 정책이 적용됩니다: 광고 없음, 추적 없음, 개인정보처리방침 제공으로 대응합니다.

## 미성년 정책 준수 요약

- 광고 없음(광고 SDK 미탑재).
- 추적·광고 식별자 미사용.
- 위치·연락처·결제 정보 미수집(학생 앱 기준).
- 개인정보처리방침 상시 제공(`https://www.smoat.co.kr/privacy`).
- 데이터 삭제 요청 경로 제공(담당 학원 또는 info@neander.co.kr).

## 확정 필요(openQuestion)

- IARC 설문은 콘솔에서 직접 응답해야 등급이 확정됩니다. 본 문서는 답변 지침이며, 실제 산정 등급은 제출 후 확인합니다.
- 미성년(특히 14세 미만) 이용 가능성이 있는 경우, 개인정보처리방침의 법정대리인 동의(PIPA) 조항 보강이 필요합니다(`privacy-policy-mapping.md`).
