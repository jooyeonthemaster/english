# Google Play 데이터 안전 (Data Safety)

Google Play Console의 `데이터 안전` 양식에 입력할 값입니다. Apple App Privacy 라벨(`apple/app-privacy-labels.md`)과 동일한 코드 근거에서 도출했으며, 두 스토어 신고가 어긋나지 않게 정합을 맞춥니다. 학생 앱(`/g` 표면)이 실제로 처리하는 데이터만 신고합니다.

## 전역 신고

- **데이터를 수집·전송합니까?**: 예.
- **전송 중 암호화(Data encrypted in transit)**: 예(HTTPS).
- **사용자가 데이터 삭제를 요청할 수 있습니까?**: 예. 담당 학원 또는 info@neander.co.kr로 요청합니다.
- **광고·마케팅 목적 수집**: 아니오.
- **데이터를 제3자와 공유합니까?**: 아래 `AI 처리 주석`의 결정에 따릅니다(원칙적으로 서비스 제공자 처리이므로 `공유` 아니오).

## 수집 데이터 유형 매핑

| Play 데이터 유형 | 수집 | 공유 | 처리 목적 | 필수/선택 | 코드 근거 |
| --- | --- | --- | --- | --- | --- |
| 이름(Personal info > Name) | 예 | 아니오 | 앱 기능 | 필수 | 로그인 세션 · `me-client.tsx` studentName |
| 사용자 ID(Personal info > User IDs) | 예 | 아니오 | 앱 기능, 계정 관리 | 필수 | `grammar-drill/auth.ts` 세션 · 학생코드 |
| 앱 상호작용(App activity > App interactions) | 예 | 아니오 | 앱 기능 | 필수 | 드릴·시험·과제 풀이 기록 · `engine.ts` |
| 인앱 검색·기타 사용자 생성 콘텐츠(App activity > Other user-generated content) | 예 | 아래 주석 | 앱 기능 | 선택 | AI 튜터 질문 텍스트 ≤600자 · `chat/route.ts` |
| 앱 성능·진단(App info and performance / Device or other IDs 아님) | 조건부 | 아니오 | 앱 기능, 부정 이용 방지 | 필수 | IP·접속 로그(레이트리밋) |

> IP 주소는 Play 데이터 안전에서 독립 항목이 아니라 `대략적인 위치`나 로그 맥락과 혼동되기 쉽습니다. 본 앱은 위치를 수집하지 않으므로 `위치`는 신고하지 않으며, IP는 부정 이용 방지·접속 로그 목적의 처리로 개인정보처리방침에 근거해 남깁니다. 콘솔 항목에 IP 전용 칸이 없으면 별도 신고 없이 방침 기재로 갈음합니다.

## 각 항목 세부 답변

- **이름 / 사용자 ID / 앱 상호작용**
  - 수집: 예 · 공유: 아니오 · 목적: 앱 기능(및 사용자 ID는 계정 관리) · 필수
  - 전송 중 암호화: 예 · 삭제 요청 가능: 예
- **기타 사용자 생성 콘텐츠(AI 튜터 입력)**
  - 수집: 예 · 목적: 앱 기능 · 선택
  - 공유 여부: `AI 처리 주석` 결정에 따름
  - 전송 중 암호화: 예 · 삭제 요청 가능: 예

## 수집하지 않는 데이터(명시적 아니오)

- 위치(정밀·대략) — 위치 권한 없음.
- 금융·결제 정보 — 학생 앱에 결제 없음(강사 전용 웹에만 존재, 도달 불가).
- 연락처(전화·이메일) — 학생 로그인은 코드 기반.
- 기기·광고 식별자 — 광고 SDK 없음, 추적 없음.
- 건강·피트니스·메시지·사진·연락처 목록 — 수집하지 않음.

## AI 처리 주석(공유 분류 결정)

AI 어법 튜터의 질문 텍스트는 답변 생성을 위해 AI 모델 제공자(Google Gemini, atlas 게이트웨이 경유)로 전송됩니다(근거: `api/grammar-drill/chat/route.ts`).

- **원칙(권고)**: 이는 서비스 제공자(subprocessor)에 의한 처리이며, Google Play 데이터 안전에서 `제3자와 공유`는 서비스 제공자 처리를 제외하므로 `공유 = 아니오`로 신고합니다.
- **보수적 대안(openQuestion)**: 무학습(모델 학습 미사용) 계약이 문서로 확정되지 않은 동안에는, 심사 안전을 위해 `기타 사용자 생성 콘텐츠`를 `서비스 제공자와 공유`로 신고하는 편을 택할 수 있습니다. 이 경우 Apple 라벨과의 정합을 위해 `apple/app-privacy-labels.md`의 주석도 함께 갱신합니다.
- 어느 쪽이든 광고·추적 목적은 아니며, 전송 중 암호화와 삭제 요청 가능은 `예`를 유지합니다.

## 삭제 경로

학생은 앱 내에서 계정을 생성하지 않으므로 인앱 계정 삭제 버튼이 없습니다. 데이터 삭제는 info@neander.co.kr(개인정보처리방침 §8·§10 근거) 또는 담당 학원(계정 발급 주체)으로 요청합니다. '담당 학원' 채널과 학생·보호자 특정 삭제 조항의 방침 명문화는 제출 전 보강 예정입니다(`privacy-policy-mapping.md` #4·#5).

## 확정 필요(openQuestion)

- AI 튜터 입력의 `공유` 분류 최종 결정(원칙 vs 보수적 대안).
- 콘솔 UI의 최신 항목 명칭에 맞춘 세부 매핑.
