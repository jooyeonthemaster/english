# smoat IR Deck — 인터랙티브 리딩 덱

스파크랩 **Spark Claw Cohort 01** 지원용 IR 자료. 발표자 없이 읽히도록 설계된
"리딩 덱"(헤드라인=결론, 슬라이드당 1주장)이며, 8막 27장 구성입니다.

## 실행

빌드가 필요 없는 정적 사이트입니다.

```bash
# 방법 1 — 서비스 경로 (운영): https://smoat.co.kr/ir
#   public/ir/ 에 사본이 서빙됨. 메인 어디에도 링크하지 않는 비공개 경로.
#   이 폴더(ir-deck/)가 원본 — 수정 후 반드시 동기화:
node scripts/sync-ir-deck.mjs
#   /ir 클린 URL은 next.config.ts 의 rewrites 가 처리. prod 반영은 다음 배포 시점.

# 방법 2 — 더블클릭
index.html 을 브라우저로 열기 (CDN 폰트만 온라인 필요)

# 방법 3 — 로컬 단독 서버 (PDF 재생성 시 필요)
npx http-server ir-deck -p 4173
# → http://localhost:4173
```

주의: `_qa/`(검수 스크린샷)·`_pdf/`(캡처 파이프라인)·PDF·이 README는
public/ 으로 절대 복사하지 않습니다 — sync 스크립트가 덱 파일 6개만 복사합니다.

## 조작

| 입력 | 동작 |
|---|---|
| 클릭 / `→` `↓` `Space` `Enter` `PgDn` | 다음 스텝 |
| 좌측 18% 클릭 / `←` `↑` `Backspace` `PgUp` | 이전 스텝 |
| `F` | 전체화면 |
| `Home` / `End` | 처음 / 끝 |
| 우하단 ≡ | 목차 |
| URL 해시 `#12.2` | 13번째 슬라이드 3번째 스텝으로 딥링크 |

9번 슬라이드(인터랙티브 체험)는 `[data-ui]` 영역이라 패널 안 클릭은
슬라이드를 넘기지 않습니다 — 문제 생성 시뮬레이션 + 워크북 결정론 리롤.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 27장 슬라이드 전체 마크업 (콘텐츠 수정은 여기) |
| `deck.css` | 디자인 시스템 — 컬러 토큰·글래스·타이포·HUD |
| `slides.css` | 슬라이드별 레이아웃 |
| `deck.js` | 덱 엔진 — 스텝 리빌·네비게이션·카운트업·SVG 드로우 |
| `demo-data.js` | 체험 섹션 데이터 (지문 1 + 문항 4유형: 빈칸/어법/순서/요약) |
| `demo.js` | 계절성 차트 생성·지도 그리드·체험 데모 로직 |
| `_qa/` | Playwright 검수 스크린샷 (삭제해도 무방) |

## 콘텐츠 수정 가이드

- **스텝 안무**: 요소에 `data-s="N"` (N번째 클릭부터 표시), `data-d="1~6"`(지연),
  `data-fx="left|right|pop"`(등장 방향), `data-dim-at="N"`(N스텝부터 흐려짐).
- **슬라이드 추가**: `<section class="slide" data-act="막이름" data-title="목차 제목"
  data-steps="스텝수">` — 엔진·HUD·목차가 자동 반영.
- **숫자 출처**: 시장 수치는 교육부·국가데이터처 2025 사교육비 조사,
  유닛 이코노믹스는 자사 요금표(크레딧 2cr/문항 × 73~132원/cr) 기준 검산값.
