[요약]
이번 업데이트는 카드 클릭 방식, 지문 등록 흐름, 학습자료 편집기를 중심으로
작업 속도와 출력 품질을 개선한 업데이트입니다.

핵심 변화:
- 카드 안의 작은 "상세보기/가져오기" 버튼을 줄이고, 카드 자체를 누르면 바로 열리도록 개선
- 추출 자료를 여러 지문으로 한 번에 가져와 분석할 수 있는 지문 등록 흐름 추가
- 학습자료 편집기에서 정답지, 단어 시험지, 표지/로고/디자인 설정을 더 쉽게 조절
- 학습자료 출력 시 페이지 분할, 정답지, 단어 시험지, 어휘 선정 품질 개선


----------------------------------------------------------------
1. 카드 클릭 UX 개선
----------------------------------------------------------------
- 지문, 문제, 시험지, 자료 추출 카드에서 작은 "상세보기" 버튼을 누르지 않아도
  카드 자체를 클릭하면 상세 화면이 열리도록 바뀌었습니다.
- 자료를 가져오는 카드도 카드 자체를 누르면 가져오기 동작이 실행됩니다.
- 카드 위에 마우스를 올리면 하늘색 "상세보기" 또는 "가져오기" 문구가 표시됩니다.
- 드래그 선택 기능은 유지하면서, 선택과 상세 열기 동작이 헷갈리지 않도록 정리했습니다.


----------------------------------------------------------------
2. 지문 등록 / 자료 가져오기 개선
----------------------------------------------------------------
- 추출된 자료를 하나씩만 불러오는 방식에서, 여러 자료를 지문 블록으로 쌓아
  한 번에 분석할 수 있는 흐름으로 개선했습니다.
- 지문 블록을 추가, 삭제, 접기/펼치기 할 수 있어 여러 지문을 한 화면에서 관리하기 쉬워졌습니다.
- 각 지문 블록마다 제목, 본문, 출처, 이미지 첨부를 따로 다룰 수 있습니다.
- 왼쪽 자료 목록에서 선택한 자료가 가운데 지문 입력 영역에 반영되고,
  이미 가져온 자료는 눌린 상태로 더 명확하게 표시됩니다.
- 여러 지문을 분석할 때 필요한 크레딧도 지문 수 기준으로 더 명확하게 계산됩니다.


----------------------------------------------------------------
3. 학습자료 편집기 개선
----------------------------------------------------------------
- 정답지·해설지 포함 여부를 편집기 오른쪽 상단에서 바로 켜고 끌 수 있게 했습니다.
- 새 학습자료를 만들 때는 기본적으로 정답지·해설지가 포함됩니다.
- 단어 시험지도 오른쪽 상단에서 ON/OFF 할 수 있고,
  버튼 옆 세부 설정에서 "뜻 쓰기", "단어 쓰기", 레이아웃, 단어 시험지만 만들기를 조절할 수 있습니다.
- 학습자료 설정의 ON/OFF 버튼 디자인을 실제 스위치가 들어간 형태로 통일했습니다.
- 표지, 로고, 학원명, 영어 원문 페이지, 디자인 설정을 하나의 "설정 템플릿"으로 저장하고 적용할 수 있습니다.
- 중복되던 로고 단독 저장, 표지 프리셋 저장 기능은 제거해 설정 구조를 단순화했습니다.


----------------------------------------------------------------
4. 학습자료 출력 품질 개선
----------------------------------------------------------------
- 정답지와 해설지가 긴 경우에도 한 덩어리로 잘리지 않도록, 하위 영역별로 나누어 출력되게 개선했습니다.
- 단어 시험지는 기본 핵심어 중 너무 쉬운 단어를 덜 포함하고,
  시험에 나올 만한 중상 난도 표현을 더 중심으로 구성되도록 조정했습니다.
- 단어장 표에서는 별도의 난이도 표시는 제거해 학생이 보는 화면을 더 깔끔하게 정리했습니다.
- 단어 시험지 빈칸과 정답 작성 라인의 가독성을 개선했습니다.
- 섹션 제목과 주요 블록의 페이지 분할, 높이 조절이 더 자연스럽게 동작하도록 보정했습니다.


----------------------------------------------------------------
5. 편집 편의성 개선
----------------------------------------------------------------
- 학습자료 편집기에서 일부 텍스트만 선택해 글자 크기를 다르게 줄 수 있는 기반이 추가되었습니다.
- 블록 높이 조절 시 페이지 밖으로 과하게 밀려나지 않도록 보정했습니다.
- 여백 블록이 너무 작아져 잡기 어려운 문제를 줄였습니다.
- 상단 작업 큐와 카드형 목록도 카드 클릭 중심으로 정리해 버튼이 덜 복잡해졌습니다.


----------------------------------------------------------------
6. 기타 정리
----------------------------------------------------------------
- 자료 관리, 문제 관리, 시험지 관리, 작업 큐의 카드 액션 디자인을 통일했습니다.
- 드래그 선택과 카드 열기 동작이 함께 쓰이는 화면에서 충돌을 줄였습니다.
- 학습자료 설정과 블록 편집 패널의 문구와 배치를 더 간결하게 정리했습니다.
