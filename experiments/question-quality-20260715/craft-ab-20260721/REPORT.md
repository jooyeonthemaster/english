## 판정
1. **공예 프롬프트의 효과는 실재하나 모델 상한에 종속.** 방향반대 조합 규칙 등 기제 분류학은 grok 에서 크게 산다(빈칸 craft 7.0→7.9, A 2→7). flash3 에선 미미(+0.1~0.3, A 변화 없음) — O194 "공예 상한 grok > pro ≫ 저가" 재확인. 사용자의 3.1pro 채팅 데모 수준은 pro31 프로덕션 계약(스키마 강제) 아래서 재현되지 않음(craft 6.6~7.0) — 데모의 아름다움 일부는 자유 텍스트+무스키마 형상에서 온다.
2. **빈칸 C(공예+검수리) = F 0/30 + craft 소폭 우위** — 검수리가 공예를 깎지 않으면서 B 의 F(3건: grok 한국어 파손 2·수일치 1)를 전부 막았다. 공예 프롬프트+검수리 조합은 안전하다.
3. **어법의 신형 F 계통 발견: 마커 위치-해설 불일치** (동일 표현이 지문에 2회 이상 등장할 때 밑줄이 해설과 다른 발생 위치에 표시) — F 9건 중 5건. 모델 불문(grok·pro31·flash3). **결정형 게이트 후보**(마커 표현의 다중 발생 검출 + 해설 지칭 문장 대조). + build up 자동사 성립 논쟁성 2건(grammar-disputed-usage 축).
4. **어법 B×flash3(공예 1콜)이 현행 사다리 대비 흥미로운 대안**: craft 6.1→6.9, 시간·원가 소폭 절감, 대가 F 0→1(마커-해설 불일치 계열 — 게이트 신설 시 방어 가능).
5. grok 는 공예 상한이 확인되나 시간(빈칸 228~276s·어법 476s+)이 현행 UX 와 비호환 — 단일 상품에는 부적합, "느려도 최고 공예" 별도 상품이 아니면 채택 불가.
