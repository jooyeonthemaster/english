## 배경 (먼저 읽을 것)
- `experiments/question-quality-20260715/research-note.md` 의 **O202, O208, O208-b** — 판례 전부.
- 구조적 원인: 지문은 학원들의 시험지 업로드로 들어온다. ①같은 시험이 학원 수만큼 복제 저장되고 ②**어법(29번)·어휘(30·42번) 출처 지문은 오답 단어가 심긴 출제 변형본(인쇄본)이 그대로 저장**된다.
- 확정 판례 5건: 수정 4건(distinguishable→indistinguishable, which→in which, confuse→help ×8행, having→have ×6행), **반증 1건(cmrs0c5z9 — 비문처럼 보이지만 학평 원문 그대로. "어색함"은 오염의 증거가 아니다)**.
- 참고: `experiments/question-quality-20260715/db-audit/` (검사·수정 스크립트 원형, 시험지 PDF 일부). DB 는 `.env.local` 의 DATABASE_URL, tsx+Prisma.

## 판정 방법 — AI 복원 우선 (해설지는 보너스)
오염 후보 지문마다 다음 3단으로 판정한다:
1. **솔버 에이전트(고성능, 문항당 1개)**: 이 지문이 어법/어휘 문항 출처임을 전제로, 지문을 정독하고 "심긴 오답 단어"가 있는지·어디인지·원형이 무엇인지를 스스로 풀어서 복원안을 낸다. 마커(①~⑤)가 본문에 잔존하는 사본이 있으면 그 위치가 심긴 자리라는 강한 증거로 쓴다.
2. **독립 적대 검증 에이전트 1개**: 1의 결론을 모른 채 같은 지문을 풀게 하고, 두 에이전트가 **같은 위치 + 같은 교정**으로 수렴할 때만 "오염 확정"으로 채택한다. 위치가 다르거나 한쪽이 "결함 없음"이면 → 미확정(수정 금지, 보고만).
3. **웹 교차 확인(가볍게)**: 시험명+문항번호+단어로 한국 해설 블로그/호랭이닷컴 스니펫을 1회 검색해 인용이 잡히면 확정 근거로 첨부(못 찾으면 그만 — 병목 금지). PDF 는 이미 있는 것만 쓰고 새로 구하러 다니지 마라.

복원 정밀도 원칙: **어법 복원은 문법이 원형을 유일 결정하므로 그대로 채택**. **어휘 복원은 "문맥상 옳은 단어"로 복원하되 최소 수정을 우선**(부정 접두어 뒤집기 > 자연스러운 최빈 대체어). 목적은 "지문이 논리·문법적으로 성립"이지 원저 축자 재현이 아니다.

## 절대 원칙
1. "비문처럼 보인다" 단독으로 수정 금지 — 이중 에이전트 수렴 없으면 미확정 (cmrs0c5z9 판례).
2. **수정 전 대상 행 전체 JSON 백업** (`experiments/question-quality-20260715/passage-fix-backup-YYYYMMDD-<이름>.json` 관례).
3. 오염 1건 = N행. **내용 기준 dedup(앞 60자 head)으로 같은 지문 전 사본을 찾아 일괄 수정**, 마커 잔존 사본("④ having"류)도 단어만 교정.
4. `\b` 단어 경계 정규식으로 매칭 1회 검증 후 교체 — 1회가 아니면 스킵하고 보고.
5. 수정 후 재조회로 오염 문자열 잔존 0 검증.

## 진행 순서
1. **위험군 도출**: Passage 전수에서 (a)제목/태그에 어법·어휘 또는 29·30·42가 붙은 기출 지문 (b)본문에 원형숫자 마커(①~⑤) 잔존 지문 추출 → 내용 dedup → "고유 지문 × 시험" 단위 목록 (O202 때 ~54건 방식 — 재도출, 저장본 없음).
2. **시험지 단위 그룹핑** (고1 6월에서 29·30 연속 오염 — 오염은 시험지 단위다).
3. 고유 지문마다 위 3단 판정 → 확정이면 백업 후 전 사본 일괄 수정.
4. **기록**: research-note.md 상단 O2xx append — 시험별 판정표(확정/반증/미확정 + 근거 1줄), 수정 내역(교정 전→후·행수·백업 경로), 마커 잔존 지문 목록(정리는 후속 과제).
