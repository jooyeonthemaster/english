# Original connectivity-pilot source

This package contains one newly composed, PII-free English passage used only by the two-call v6 connectivity run-in. Its exact text and provenance record are kept in a directory-local git-ignored private artifact. The public artifact contains only a content commitment and aggregate measurements.

The row is deliberately outside the twelve-passage S1 corpus. Neither the row nor either generated run-in output may enter S1/S2/S3/S4 analysis, prompt-profile selection, reviewer calibration, or a release claim. This avoids spending two operational probes and then quietly treating the observed passage as blinded experimental evidence.

The requesting user authorized external-model question-generation research. The row-level record limits that permission to the separately admitted v6 connectivity pilot; it does not by itself authorize dispatch. Exact provider privacy routing, price freshness, physical-call/candidate/cost leases, and the pilot controller must still pass.

Offline verification checks the exact content commitment, word/sentence/byte measurements, common PII patterns, git-ignore boundary, public text leakage, and eight-token overlap against the twelve S1 v6 passages. It makes no network, model, provider, or database call.
