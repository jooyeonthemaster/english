# All-types evaluation rubric v1

Status: **FROZEN EVALUATION CONTRACT — NO ITEM OR RELEASE CLAIM**

This rubric covers the exact 25 active English Workbench types. Every evaluator solves the student surface before seeing the stored key and explanation. Grades are `F/C/B/A`; any answer-cardinality, source, grammar, rendering, task, or factual-explanation failure is `F` regardless of style. `A` is stricter than validity: every visible element must have a purposeful misconception-testing role and the reasoning path must be elegant and economical.

The 23 non-focus types receive exactly four sentinel rows each—`STANDARD_BASIC`, `STANDARD_KILLER`, `PREMIUM_BASIC`, and `PREMIUM_KILLER`—for 92 rows total. These rows are existence-of-defect probes only. Four clean rows cannot estimate a type-level rate, compare plans, rank models, establish noninferiority, or authorize release. The earlier “12 rows per type” text was stale and is superseded.

Reviewer certification is per reviewer and family-scoped. It covers the exact five-marker/one-invalid `GRAMMAR_ERROR` surface, the seven-axis `BLANK_INFERENCE` oracle, and only the evidence families actually represented in sealed gold items; it never certifies all 25 types by implication.

No model/API/network/DB call or full-question candidate was used to amend this artifact.
