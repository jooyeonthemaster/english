작성: 2026-07-16 KST. 사용자 직접 지시로 live API 실험 실행이 승인됨(대화 기록이 승인 근거).
예산: 완성 문항 후보(full-question candidate) **1,000개 하드캡**, `budget-ledger.json` 원장 계속 사용.
모델 고정: STANDARD=`google/gemini-3.5-flash`($1.5/M in, $9/M out), PREMIUM=`google/gemini-3.1-pro-preview`($2/M in, $12/M out). 설계(design)·평가(evaluation) 보조 콜은 slot을 소비하지 않지만 콜·토큰·비용은 전부 원장에 기록한다(PROTOCOL §7).

## 원칙 (이전 세션에서 계승, 재위반 금지)

1. 후보 slot은 full-question 생성 경계 진입 직전에 소비하고, 실패해도 환불하지 않는다.
2. n<10 결과로 arm을 죽이지 않는다(조기중단 규칙 충족 시 예외: 파일럿 n=8에서 치명 2건+비용 2배).
3. 스크리닝(n=10)은 승격/기각 판단만. 확정 주장에는 n≥30/arm paired + 독립 이중평가.
4. 생성자와 평가자 분리: 평가는 별도 컨텍스트의 독립 에이전트가 RUBRIC.md로 수행. 블라인드 풀이가 먼저다.
5. 치명(V1–V5) 결함은 공예 점수로 상쇄 불가.
6. 판단 지표는 fatal-free rate, ship-ready rate(B 이상), beautiful-killer rate, **cost-per-ship-ready**, latency.
7. 기각안 부활 금지: STANDARD+사다리, Flash diet 사다리, Pro 단독, Claude 단순 교체, 금지목록 무한 추가.

표기: F=gemini-3.5-flash, P=gemini-3.1-pro-preview. slot 소비는 full-question 생성 콜 기준.
