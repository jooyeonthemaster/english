# Deterministic 2D Dress-up Warp Lab

5개의 서로 다른 체형 사진과 5개의 동일한 의상 원본을 조합해 25개 결과를 만드는 비생성형 프로토타입입니다. 합성은 고정 토폴로지 삼각 메시와 Canvas 2D affine texture mapping만 사용합니다.

> 현재 단일 공용 메시 실험은 엄격한 왜곡 한계값을 25/25 모두 초과했습니다. 성공 데모가 아니라 단일 에셋 접근의 실패 경계를 재현하는 실험입니다. 기술·제품 결론은 [REPORT.ko.md](./REPORT.ko.md)를 먼저 읽어 주세요.

## 실행

```powershell
cd experiments/deterministic-dressup
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. `메시 워핑`과 `단순 스케일`을 전환할 수 있으며 `메시 보기`로 실제 삼각형을 확인할 수 있습니다.

## 중요한 경계

- 의상 이미지는 임의의 접힌 상품 사진이 아니라, 한 번만 제작한 정면 캐노니컬 스프라이트입니다.
- 사람별 의상 이미지 재생성이나 보정은 없습니다. 동일한 PNG와 메시 토폴로지를 사용합니다.
- 현재 인체 점은 실험용 수동 주석입니다. 제품에서는 MediaPipe Pose + 실루엣/폭 측정으로 대체합니다.
- 2D 워핑은 픽셀을 이동할 뿐, 보이지 않는 옷 면·주름·그림자·천의 두께를 새로 만들지 않습니다.
- 화면의 stretch 값은 삼각형 면적 변화의 중앙값 대비 최악 비율입니다. 2.5배 초과 또는 뒤집힘은 하드 실패 후보입니다.
