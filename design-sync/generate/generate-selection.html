선택 카드 · 옵션 컨트롤 (생성 3페이지 공통 상태 언어)

"선택됨 = 파랑" 단일 원칙. 카드 선택은 파랑 테두리+연한 파랑 링, 옵션 선택은 border-blue-300 bg-blue-50 text-blue-700, 세그먼트 활성은 흰 리프트 또는 파랑 채움. 경고(검수 필요)만 red 계열.

1. 선택 카드 (지문 · 문항) — 기본 / 선택됨(+순서 배지) / 검수 필요

border-slate-200
hover: border-blue-300 + shadow

ring-2 ring-blue-300/30

선택 순서 배지 rounded-full bg-blue-600 text-[10px] text-white tabular-nums. 다중 선택 시 체크 순서(1, 2, 3…)를 노출.

2. 옵션 세그먼트 (버튼형 라디오) — 설정 패널 표준

3. 세그먼트 토글 두 변형 — white-active(난이도·필터) / solid(모드 전환)

white-active: 트랙 bg-slate-100 p-0.5 + 활성 bg-white text-blue-700 shadow-sm. solid: 흰 테두리 컨테이너 p-1 + 활성 bg-blue-600 text-white.

4. 숫자 스테퍼 · 토글 스위치

3 0

스테퍼 값칸은 값>0이면 bg-blue-50/50 text-blue-700, 0이면 bg-slate-50/60 text-slate-300 — 채워진 곳이 한눈에 보임. 스위치 on bg-blue-500 / off bg-slate-200~300.
