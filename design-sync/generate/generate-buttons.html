생성 버튼 셋 — 문제 · 시험지 · 학습지 공통

세 생성 페이지에서 통일되어 나타나는 버튼 체계. 핵심 규약: 생성(비용 발생 액션) = 파랑 blue-600, 저장 = 검정 slate-900("저장" 한 단어 + Save 아이콘 고정), 보조/도구 = slate 아웃라인. 학생관리 하위 페이지 설계 시 이 위계를 그대로 적용.

1. 주 생성 CTA — h-12 · rounded-xl · bg-blue-600 · 파랑 그림자 · 라벨에 수량 명시

크레딧 소모는 CTA 내부 우측 반투명 칩 rounded-lg bg-white/20 px-2 py-1 text-[11px](Coins 아이콘 + 숫자, 0이면 "무료"). 비활성 상태는 회색 전환(bg-slate-200 text-slate-400)이 표준이며, 라벨이 다음 행동을 안내("지문을 선택하세요"). 비활성은 native disabled 대신 aria-disabled로 클릭을 살려 힌트 글로우(Patterns 카드) 유도. 시험지 빌더처럼 크레딧을 쓰지 않는 페이지는 칩 없이 동일 형태.

2. 저장 = 검정 (전역 SaveButton) — h-8 · slate-900 · text-[11px] · split 지원

3. 보조 · 도구 버튼 — h-8 · rounded-md · slate 아웃라인 (인쇄/다운로드/실행취소)

강조 보조 액션(배포 등)은 Toss 블루 아웃라인: border-[#3182F6]/45 text-[#3182F6] hover:bg-blue-50.

4. 아이콘 액션 — size-7 파랑틴트 hover / 닫기 고스트 / 파괴적 red 아웃라인

일반 아이콘 액션은 size-7 rounded-md border-slate-200 hover:border-blue-200 hover:bg-blue-50 hover:text-blue-700. 모달 닫기 X는 테두리 없는 고스트(text-slate-400 hover:bg-slate-100). 파괴적 액션만 red 아웃라인.

5. 모바일 하단 고정 바 — 이전(아웃라인 h-11) + 다음(파랑 flex-1) / 최종 CTA h-12 extrabold

최종 CTA의 모바일 비활성은 연파랑(border-blue-200 bg-blue-300) — "곧 갈 수 있는 길"을 시각화. 스텝 네비 비활성은 회색(bg-slate-200 text-slate-400).
