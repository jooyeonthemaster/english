## 공통 사용 원칙

- 웹에서는 원본의 `aspect-ratio: 16 / 9`를 유지하고 `object-fit: cover`를 사용한다.
- 모바일 세로 광고는 인물이나 핵심 제품이 있는 쪽을 중심으로 4:5 크롭한다.
- 카피는 이미지에 직접 재합성하지 않고 HTML, 디자인 툴 또는 광고 플랫폼의 텍스트 레이어로 올린다.
- 흰색 또는 매우 옅은 청색 글자와 코발트 CTA를 기본 조합으로 사용한다.
- 시험지 내부의 작은 문자는 정보 전달용 본문이 아니라 시각적 구조이므로 확대 소재로 사용하지 않는다.

## 생성 방식

네이티브 Codex 이미지 생성 기능으로 제작했다. 외부 이미지 생성 API나 프로젝트 백엔드는 사용하지 않았다. 06–31번은 프로젝트에 포함된 실제 SMOAT 화면과 출력물을 삽입 소재로 사용했다.
