> **영어 강사 내신 대비 올인원 · 2시간 세미나용 16:9 인터랙티브 덱 (27장)**
> 컨셉 한 문장: *지문 한 장이 라인에 오르면, 문항·시험지·학습지·과제·리포트가 끝까지 흘러 — 다시 라인 입구로 돌아온다.*

---

## 여는 법

`index.html` 을 **더블클릭**하면 끝입니다. 서버·설치 불필요.
발표 시작 전 **`F` 키로 전체화면**을 권장합니다.

## 조작

| 키 / 동작 | 기능 |
|---|---|
| `→` `Space` `PgDn` · 화면 우측 클릭 | 다음 스텝 / 다음 공정 |
| `←` `PgUp` · 화면 좌측 클릭 | 이전 |
| **`G`** 또는 `Esc` | **LINE MAP(공정도)** 열기·닫기 — 칸을 누르면 그 공정으로 점프 |
| 숫자 입력 (예: `1` `8`) | 해당 번호 공정으로 점프 |
| `Home` / `End` | 처음 / 마지막 |
| `F` | 전체화면 |
| 상단 **레일 노드 클릭** | 그 공정으로 이동 |
| 마우스 휠 | 이동 (목업·스크롤 영역 위에서는 내부 스크롤) |

## 화면 크롬 읽는 법

- **상단 레일** — 27개 공정 노드. 지나온 공정은 채워지고 현재 공정이 발광합니다.
- **상단 좌측** — `SMOAT LINE` / 구역(개막·문제·생성·산출·전환·배포·학습·회수·순환·확장·정리) / `공정명 / NN—27`
- **상단 우측** — 현재 파트 + 경과 타임코드 (2시간 페이스 조절용)
- **하단 READOUT** — `IN ▸ 이 공정에 들어오는 것` … `OUT ▸ 나가는 것`.
  **앞 공정의 OUT = 다음 공정의 IN.** 흐름이 끊기지 않는다는 걸 매 장표가 스스로 증명합니다.

## 구조

```
seminar-deck/
├─ index.html            ← 이걸 엽니다 (빌드 산출물)
├─ template.html         셸 (폰트 CDN + HUD + LINE MAP)
├─ slides/s00…s26.html   슬라이드 1장 = 파일 1개 (s00=표지. 파일번호 ≠ 상영번호, s00→1번)
├─ assets/
│  ├─ css/tokens.css     팔레트·타이포 토큰 (SMOAT 제품 토큰 상속)
│  ├─ css/deck.css       엔진 + LINE 크롬 + 공용 프리미티브
│  ├─ js/deck.js         스케일·해시 라우팅·스텝·레일·READOUT·LINE MAP
│  └─ img/               실제 제품 산출물 (웹툰·학습지·시험지 실물)
├─ docs/
│  ├─ STORYLINE.md       컨셉 선언 + 27장 아크 + 서사 규율
│  ├─ DESIGN_BIBLE.md    캔버스·안전영역·토큰·금지사항
│  ├─ COPY_SPEC.md       전 장표 확정 자구 + 근거 원장 + 금지 조항
│  ├─ RECON.md           코드베이스 정찰 종합
│  └─ RECON-RAW.md       정찰 원문 11각도 (제품 UI 시각 스펙)
└─ scripts/
   ├─ build.mjs          slides/*.html → index.html 조립 + 규약 검증
   ├─ snap.mjs           전수 캡처 → shots/chNN.png
   ├─ safearea.mjs       안전영역 침범 좌표 자동 감사
   ├─ functest.mjs       행동 게이트 (내비·오버뷰·인터랙션 35항)
   └─ probe.mjs          단일 슬라이드 인터랙션 캡처
```

## 수정하는 법

1. `slides/sNN.html` 을 고칩니다 (CSS는 반드시 `#sNN` 스코프 안에서).
2. `node scripts/build.mjs` — `index.html` 재조립.
3. 검증: `node scripts/safearea.mjs` (침범 0건) · `node scripts/functest.mjs` (35/35).

**카피를 고칠 때는 `docs/COPY_SPEC.md` 를 먼저 고치세요.** 그 문서가 자구의 단일 진실원입니다.

## 이 덱이 쓰는 사실의 출처

전 수치·명칭은 SMOAT 코드베이스에서 관측된 값만 씁니다 (`docs/COPY_SPEC.md` §0 근거 원장).

**적중 장표(24·25)만 예외적으로 외부 1차 증거를 씁니다.** 강사 선생님들이 보내주신
카카오톡 **원본 캡처 2장**이 근거이며, 캡처에 실제로 적힌 문장·숫자 밖으로 나가지 않습니다.
적중률·집계·평균 같은 지표는 **여전히 전면 금지**입니다 (`COPY_SPEC.md` §0-적중).

문항 유형 25종, 크레딧 단가, 학습지 22쪽, 어법 드릴 12유닛×47개념, 리포트 데모 데이터까지
전부 제품 소스 기준이며, 세미나 운영 정보(2시간·300크레딧·앱 출시 준비 중)는 주최자 브리프가 원출처입니다.

**대외비**: 국어 과목 기능은 이 덱에 일절 등장하지 않습니다.
