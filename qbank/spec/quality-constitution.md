## §0 이 프로젝트가 사설 모의고사와 다른 점 (먼저 읽어라)

| 축 | 사설 모의고사 스킬 | **이 프로젝트** |

여기서 타협하면 이 프로젝트는 존재 이유가 없다.

유형이 요구하는 **구조적 변형만** 허용한다. 그 외 지문은 한 글자도 건드리지 않는다.

| 허용 | 유형 | 변형 내용 |
|---|---|---|
| ○ | `BLANK_INFERENCE`, `SUMMARY_COMPLETE*`, `FILL_BLANK_KEY` | 특정 표현을 빈칸으로 치환 |
| ○ | `GRAMMAR_ERROR`, `GRAMMAR_CHOICE_COMBO`, `GRAMMAR_CORRECTION` | 지정 지점에 문법 오류 주입 + 밑줄/네모 표기 |

| ○ | `SENTENCE_ORDER`, `SENTENCE_INSERT`, `IRRELEVANT` | 문장 분할·재배열·추출·삽입 |

## §1 A등급 문항의 조작적 정의

아래 **7개가 전부 참**이면 A등급이다. 하나라도 거짓이면 최대 B다.

1. **정답 유일성** — 블라인드 솔버(정답 비공개, 지문+발문+선지만)가 의도 정답을 confidence ≥ medium 으로 맞힌다.
2. **근거 이중화** — 정답이 지문의 **서로 다른 문장 2곳 이상**으로 방어된다. 한 문장만으로 풀리면 최대 B.
3. **오답 전건 반박 가능** — 오답 각각을 **지문 문장 하나를 직접 인용해** 배제할 수 있다. "지문에 없음"으로 끝나는 오답은 F2 하나만 허용하며 문항당 1개를 넘지 않는다.
4. **최강 미끼 실재** — 중위권이 실제로 고를 오답이 최소 1개 있고, 그것이 어느 것인지 명시돼 있다.
5. **패러프레이즈 원칙** — 정답 선지가 지문 구절의 축자 복사가 아니다. 정답이 최장 선지가 아니다. 정답만 문체·구체성이 튀지 않는다.
6. **해설 무결** — §5 해설 기준을 전건 충족.
7. **교육과정 정합** — 고교 2015 개정 교육과정 범위. 초과 어휘는 각주 처리하고, 각주 단어가 정답 단서가 되지 않는다.

### 등급표
| 등급 | 조건 |
|---|---|
| **A** | 위 7개 전부 충족 + 미끼 강도 목표 달성(§4) |
| **B** | 결함 없으나 A 조건 중 1~2개 미달 (주로 근거 이중화·미끼 강도) |
| **C** | 출제는 성립하나 설계 의도가 약함 — 미끼가 장식이거나 포인트가 평범 |
| **F** | **출하 불가.** §2 실패 축 중 하나라도 해당 |

**목표: A+B ≥ 90%, F = 0.** F는 수량으로 상쇄되지 않는다(불변조건 I8).

## §2 실패 축 (F 판정) — 선행 캠페인 V1~V4 승계

| 축 | 이름 | 정의 | 대표 사고 |
|---|---|---|---|
| **V1** | 형식 붕괴 | 필수 필드 누락·라벨 축 이탈·마커 불일치 | 0원 게이트가 전량 차단(대부분 여기서 죽는다) |
| **V2** | 정답 붕괴 | 정답 복수 성립 / 정답 없음 / 정답 누출 | 어법에서 밑줄 (A)가 축약관계절로도 성립 → 정답 2개 |
| **V3** | 오답 슬롯 부적합 | 오답이 즉사(아무도 안 고름) 또는 정답과 사실상 동일 | 소재만 확인하면 소거되는 선지가 과반 |
| **V4** | **해설 사실성** | 해설이 지문에 없는 것을 근거로 들거나, 오답 해설의 귀속이 틀림 | 캠페인 지배적 F 원인. 오답해설 주어 오귀속 |
| **V5** | 지문 오염 | 지문 자체에 오류가 있거나 원문과 다름 | 이 프로젝트 P0 게이트가 선차단 |
| **C5** | 난이도 정합 | 요청 난이도와 실제 난이도 불일치 | KILLER 요청인데 근거 1문장으로 풀림 |

**V4가 가장 자주 새고 가장 자주 놓친다.** 해설은 문항의 절반이다 — 학생이 실제로 배우는 곳이기 때문이다.

## §3 오답 공학 택소노미 (design-dna §4 승계 — 강박 수준으로 적용)

### 매력 코드 L1~L7 — 오답이 학생을 끄는 이유
| 코드 | 이름 | 정의 |
|---|---|---|
| L1 | 핵심명사 재사용 | 지문의 핵심 명사구를 그대로 씀 (표면 대조 학생 유인) |
| L2 | 부분 사실 | 선지의 절반이 지문과 정확히 일치 |
| L3 | 통념 공명 | 배경지식·상식과 부합해 지문 없이도 그럴듯함 |
| L4 | 위치 인접 | 정답 근거 문장 바로 옆 문장에서 가져옴 |
| L5 | 세련된 재해석 | "표면적 불일치 밑의 심층 합의" 같은 지적으로 보이는 프레임 |
| L6 | 형식 유사 | 정답과 같은 통사 구조·같은 축 어휘로 위장 |
| L7 | 다른 지점 참 | 지문의 다른 부분에서는 참인 진술 |

### 결함 코드 F1~F7 — 오답이 틀린 **단 하나의** 이유 (반드시 지문 문장 하나로 반박 가능)
| 코드 | 이름 | 정의 |
|---|---|---|
| F1 | 관계 왜곡 | A와 B는 지문에 있으나 그 관계(원인/주체/방향)를 비틈 |
| F2 | 무근거 | 지문 어디에도 근거 없음 |
| F3 | 과잉일반화 | 지문의 제한된 주장을 전면 확장 |
| F4 | 반대 방향 | 지문 논지와 정반대 |
| F5 | 세부 승격 | 배경·사례·수단을 목적·주제로 격상 |
| F6 | 주체 전도 | 행위 주체를 뒤바꿈 |
| F7 | 한정어 삭제/왜곡 | 한정어를 지우거나 수치·조건을 비틈 |

### 운용 규칙 (위반 = 최소 C, 3·4번 위반 = F)
1. 한 문항의 오답들은 (L, F) 조합이 **서로 달라야** 한다. 같은 F코드 2회까지 허용, **3회부터 실격**.
2. 각 오답의 반박 근거는 **지문 문장 직접 인용**으로 기록한다. "지문에 없음"으로 끝내지 말고 **어떤 문장이 그것을 배제하는지** 짚어라.
3. **최강 미끼 1개 의무** — L2/L4/L5 계열로 설계한다.
4. **정답 위장** — 최장 금지, verbatim 금지, 표면 어휘 재사용 최소화, 위치별 길이 편향 금지.
5. **극단어 금지** — always/never/only/모든/절대/유일한 으로 오답임이 드러나는 설계 금지. 반대로 정답에만 몰아도 안 된다.
6. **층위 일치** — 선지 전체가 같은 형식·비슷한 길이(±3단어 또는 최장 ≤ 최단×2). 하나만 형식이 다르면 내용을 안 읽어도 걸러진다.
7. **소재 구속** — 오답 전부 "지문에 실재하는 소재·어휘"를 재료로 만든다. 지문 밖 분야 개념을 들여오면 함정이 아니라 장식이다.

## §4 난이도 3분기 (md 레인 `MdDifficulty` 축과 정합)

| 난이도 | 정답 도출 조건 | 미끼 강도 목표 | 근거 깊이 |
|---|---|---|---|
| **BASIC** | 명시적 주제문/근거 문장을 찾으면 풀린다 | decoyPull ≥ 3 | 1문장 |
| **INTERMEDIATE** | 서로 다른 두 문장을 인과·대조로 이어야 도출된다 | decoyPull ≥ 5 | 2문장 |
| **KILLER** | (a) 정답이 추상화 1단계 번역이거나 (b) 판정 근거가 단락 전체 논지 방향이거나 (c) 반전 조건문·이중부정 추론 필요 | decoyPull ≥ 7 | 2문장 이상, 서로 떨어진 자리 |

`decoyPull` = 미끼 심사관이 0~10으로 매기는 "중위권이 이 오답을 고를 확률" 최댓값.

**금지**: 어떤 문항도 ① 배경지식만으로 풀리면 안 되고 ② 지문 없이 선지만으로 풀리면 안 된다.

### 유닛 내 난이도 분포 (이 프로젝트 고유)
유닛의 5~8문항은 난이도가 섞여야 학습 자료로 기능한다. 기본 배분:
- 5문항: BASIC 1 / INTERMEDIATE 2 / KILLER 2
- 8문항: BASIC 2 / INTERMEDIATE 3 / KILLER 3

전량 KILLER 도, 전량 BASIC 도 금지한다.

## §5 해설 기준 (V4 방어 — 가장 자주 새는 곳)

정답 해설과 오답 해설은 **별개의 산출물**이며 둘 다 아래를 충족해야 한다.

### 정답 해설
1. **논지 축 명시** — 이 글이 무엇을 주장하는지 한 문장.
2. **근거 지목** — 정답을 지지하는 지문 문장을 **직접 인용**(영어 원문 그대로, 따옴표 안)한다. 근거는 2곳 이상.
3. **연결 논증** — 그 근거에서 정답 선지로 어떻게 건너가는지. "따라서 정답"으로 끝내지 마라.
4. 지문에 없는 사실을 근거로 들지 마라. **해설이 지문을 초과하면 그 자체가 F(V4)다.**

### 오답 해설
1. 오답마다 **왜 매력적인가(L)** + **무엇이 틀렸는가(F)** + **어느 문장이 배제하는가(직접 인용)** 3요소.
2. 귀속 정확 — "②는 …"이라고 썼으면 그 내용이 실제로 ②여야 한다. **주어 오귀속은 캠페인 최다 F 사고다.**
3. 선지-해설 동행 — 선지 셔플 후에도 라벨과 해설이 어긋나지 않게, 해설 첫머리에 **기제 이름**을 적어 결정형으로 대조 가능하게 한다.

### 언어 규약 (0원 게이트가 실제로 반려한다)
- 해설·오답해설은 **한국어만**. 합니다체.
- **비한글 CJK(한자·가나) 혼입 금지.** 한글 직후 괄호 병기(예: `공(功)`)만 예외.
- **"영단어+한국어 종결어미" 짜깁기 금지** (예: `steals다`). 영어 인용은 반드시 따옴표 안에.

6. **유닛 내 5문항은 오류 지점 G코드가 전부 달라야 한다** (이 프로젝트 고유 — 포인트 다각화).

## §7 출제 포인트 다각화 (★이 프로젝트의 핵심 증분)

프로덕션은 **1콜 = 1문항**이라 이 개념이 아예 없다. 우리 유닛은 5~8문항이므로 여기가 승부처다.

### 원칙
> **같은 지문·같은 유형의 N문항은 서로 다른 인지 작업을 요구해야 한다.**
> 답만 다르고 묻는 방식이 같으면 그건 N개 문항이 아니라 1개 문항의 N개 사본이다.

### 다각화 축 (유형 무관 공통 — 유형별 축은 `craft/<SUBTYPE>.md` §8)
1. **논지 위치** — 도입 통념 / 전환점 / 기제 설명 / 사례 / 결론 중 어디를 겨냥하는가
2. **추론 층위** — 명시 확인 / 재진술 / 인과 추적 / 추상화 / 반전 적용
3. **오답 기제 구성** — 문항마다 (L,F) 조합 팔레트를 달리 짠다
4. **난이도** — §4 배분
5. **표층 형식** — 선지 언어·극성(긍정/부정)·선지 수 (해당 유형이 지원할 때만)

### 결정형 강제 (0원 게이트가 집행)
- `POINT_DUPLICATE` — 유닛 내 `point:` 값이 중복되면 차단
- `ANSWER_DUPLICATE` — 두 문항의 정답 표적이 동일하면 차단

게이트는 문자열 수준만 본다. **의미 수준 중복은 검수 렌즈 ⑤(다각화 심사)가 잡는다.**

## §8 검수 렌즈 (유닛당 전량 적용)

사설 모의고사 4렌즈에 이 프로젝트 고유 렌즈 1종을 추가한 **5렌즈**.

| # | 렌즈 | 입력 | 판정 |
|---|---|---|---|
| **①** | **블라인드 풀이** | 지문 + 발문 + 선지 **(정답·해설 비공개)** | 각 문항을 실제로 풀고 답+confidence 보고. 의도 정답과 불일치 또는 confidence low → **V2 critical** |
| **②** | **품질·사실 검수** | 전체 | 지문 대조로 해설의 모든 주장을 검증. 지문에 없는 근거·오귀속 → **V4 critical**. 근거 이중화 여부 판정 |
| **③** | **형식 규정** | 전체 + 형식 계약 문서 | 0원 게이트가 못 보는 형식 (선지 층위·길이·극단어 편중·언어 규약) |
| **④** | **미끼 심사** | 전체 | 오답마다 decoyPull 0~10 + (L,F) 코드 부여. 목표 미달 → **V3 major**. 즉사 오답 과반 → critical |
| **⑤** | **다각화 심사** | 유닛 전체(5~8문항 동시) | 문항 간 의미 중복·포인트 편중·난이도 분포 검사. 사실상 같은 문항 쌍 → **major** |

### 판정 규칙
- **critical** — 출하 불가. 반드시 수리 후 재검수.
- **major** — 수리 대상. 수리 실패 시 그 문항만 제외하고 유닛 진행.
- **minor** — 기록만. 수리 선택.
- **오탐 필터**: 종합 단계에서 "근거 있는 것만, 이미 올바른 것·이미 해결된 것·추측은 제외"를 적용한다.
  검수자는 적대 편향(0건 = 안 본 것), 종합자는 보수 편향 — 양방향 가드.
- **렌즈 ①은 반드시 정답을 모르는 상태여야 한다.** 정답을 본 솔버는 솔버가 아니다.

## §9 절대 금지 (하나라도 하면 F)

1. 지문에 없는 사실을 해설의 근거로 사용
2. 정답이 복수 성립하거나 정답이 없음
3. 정답 선지가 지문 구절의 축자 복사
4. 오답 해설의 라벨 오귀속
5. 같은 유닛에서 같은 출제 포인트 반복
6. 해설에 비한글 CJK 혼입 또는 "영단어+다" 짜깁기
7. 지문 원문 훼손 (유형이 요구하는 구조적 변형 외)
8. 각주 단어가 정답의 결정적 단서가 되게 하기
9. 고교 교육과정을 벗어난 문법·어휘 지식을 정답 판정 근거로 요구
10. **문항 수를 채우려고 품질을 낮추기** — 5개를 못 만들면 4개로 보고하고 사유를 남긴다

## §10 이 헌법의 개정

- 개정은 **감독(본체)만** 한다. 에이전트는 개정을 제안할 수 있으나 직접 고치지 않는다.
- 개정 시 `../JOURNAL.md` 에 관찰번호와 함께 사유를 남기고, 이후 팬아웃 프롬프트에 개정 사실을 명시한다.
- 실측 없이 규범을 바꾸지 않는다. 선행 캠페인의 기각 사유 "10개 표본 승자 일반화"를 반복하지 않는다.
