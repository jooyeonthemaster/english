[요약]
이번 업데이트는 시험지 빌더/워크벤치 UI 개선에 더해, origin/main에서 들어온
문제 세트 생성, 문법 교정 표시, 분석 리포트 확장, HWPX/DOCX 내보내기 개선,
피드백 프로그램 기능까지 합쳐진 통합 머지입니다.

핵심 축:
- 시험지 빌더 및 문제 관리 선택 UX 개선
- 마우스 드래그 영역 선택(마키 선택) 도입
- 문제 세트(question sets) 생성/저장/렌더링 기반 추가
- grammar correction / sentence insert 표시 품질 개선
- 분석 리포트 워크시트/편집/출력 확장
- HWPX/DOCX 내보내기 렌더링 품질 개선
- 지문분석/자료관리 필터 UI 정리
- 사이드바/설정 안내 등 사용 흐름 개선


----------------------------------------------------------------
1. 선택 UX / 드래그 선택
----------------------------------------------------------------
- 카드/리스트 영역을 마우스로 드래그해 여러 항목을 한 번에 선택하는
  DragSelect(마키 선택) 컴포넌트 추가
- 적용 영역:
  - 지문 목록
  - 문제 관리
  - 시험지 목록
  - 시험지 생성의 문항/지문 선택 영역
  - 지문 분석 자료 관리
- 선택된 카드만 네이티브 드래그 이동을 허용하도록 조정
  - 미선택 카드 위에서는 폴더 이동 드래그 대신 영역 선택이 우선 동작
- 드래그 선택 중 스크롤 가장자리 자동 스크롤 지원
- 카드/행 루트에 드래그 선택용 식별자(data-drag-item-id) 추가
- 공통 선택 훅에서 setSelectedIds를 외부로 노출해 대량 선택 상태를 직접 갱신 가능하게 변경


----------------------------------------------------------------
2. 시험지 생성 / 시험지 빌더
----------------------------------------------------------------
- 새 시험지를 처음 시작할 때 설정 버튼 옆 안내 말풍선 추가
  - "시험지 설정부터 시작하세요"
  - 닫기 가능
  - 설정 버튼 클릭 시 자동으로 사라짐
  - "다시는 보지 않기" 옵션 추가(localStorage 기준)
  - 말풍선 배경을 옅은 파랑으로 조정
- 설정 버튼 글로우만으로는 약했던 초기 행동 유도를 명확히 개선
- 검수 상태 세그먼트 버튼 높이를 줄여 주변 h-7 버튼들과 시각적 크기 통일
- "지문 직접 넣기" 버튼을 상단 작은 버튼에서 풀폭 CTA로 분리해 가시성 개선
- 시험지 빌더 문항 라이브러리에 드래그 선택 적용
- 기존 시험지 빌더 재설계 항목 유지:
  - 표지(cover page)
  - 폴더 분류 바
  - 빠른 보기 다이얼로그
  - IndexedDB 임시저장
  - 저장 템플릿 설정
  - 페이지네이션/옵션 표시/미리보기 개선


----------------------------------------------------------------
3. 문제 관리 / 문제 생성
----------------------------------------------------------------
- 문제 관리 카드와 지문별 그룹 뷰에 드래그 영역 선택 적용
- 카드 본문 클릭은 선택 토글 중심으로 동작하도록 정리
- 상세 보기/편집/삭제 등 액션과 선택 동작의 충돌을 줄임
- 검수 상태 필터(전체/미검수/검수완료)의 세로 높이를 주변 버튼과 맞춤
- 문제 생성 페이지에서 지문 선택 그리드에 드래그 선택 적용
- 문제 생성 페이지의 필터/검색 툴바 디자인 정리
  - 흰색 내부 박스 제거
  - 바깥 회색/기본 영역 안에 컨트롤이 바로 놓이도록 통일
